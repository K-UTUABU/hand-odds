# 検算表

**この表は依頼者のもの。作り手は許可なく変えない。**
作り手は、ここに書かれた「入力と正解」をそのままテスト（`src/calc/kensan.test.ts`）にする。
テストが通らないときは、実装を直すか、検算表の誤りの疑いを根拠つきで依頼者に報告する。表やテストの期待値は書き換えない。

## 書き方

| 列 | 書くこと |
|---|---|
| 番号 | 1から順に付ける |
| デッキ枚数 | デッキの総数（1〜100） |
| 引く枚数 | 初手の枚数（1〜デッキ枚数、かつ 10 以下） |
| グループと枚数 | グループ名と枚数を「名前 枚数」の形で並べる。合計はデッキ枚数以下。残りは自動で「その他」になる |
| パターンの条件 | パターンごとに、グループごとの「◯枚以上・◯枚以下」を書く。上限がなければ「上限なし」。条件が複数のパターンがある場合は、どれか1つでも成立する確率を求める |
| 正解（0〜1、小数第6位まで） | 手計算で求めた確率を、0〜1 の小数で小数第6位まで書く。分数を併記してもよい。テストは、厳密な計算の結果との差が 0.000001 未満なら一致とみなす |
| 計算の式 | 正解を導いた式。読み返して検算できる形で残す |

数字の例はあえて載せていない。例を置くと、検算せずにそのまま使われるおそれがあるため。
各行の数字と正解は、依頼者が自分で決めて、自分で計算する。
