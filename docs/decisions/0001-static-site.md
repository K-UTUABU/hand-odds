# 0001 静的サイトとして作る

- 日付：2026-11-16
- 状態：採用（依頼者が案1を選んだ）

## 背景

デッキをグループに分けて枚数を入れると、初手で条件を満たす確率が分かるツールを作る。
採用担当がインストールなしで試せること、依頼者が読み切れる軽さであることが求められる。

## 決めたこと

静的サイト（案1）として作る。計算は画面に依存しない TypeScript の関数、画面は React とし、GitHub Pages で公開する。

## 理由

サーバーも DB も要らず最も軽い。URL 1つで誰でも触れる。家計簿のフロントと同じ構成で、依頼者が読みやすい。
Java は家計簿で示せているので、サブ作品は軽さと「触れること」を優先する。
外部へ入力内容を送らず、計算はすべてブラウザの中で行う。

## 捨てた案

| 案 | 中身 | 捨てた理由 |
|---|---|---|
| 2. Spring Boot の API + 画面 | 計算を Java の API にする | 家計簿と構成が重なる。公開にサーバーが要る |
| 3. Java のコマンドラインツール | 画面なし | 採用担当が触れない |
| 進め方：GitHub を使わずローカルだけで進める | - | 任せた過程が外から見えず、意図に合わない |
